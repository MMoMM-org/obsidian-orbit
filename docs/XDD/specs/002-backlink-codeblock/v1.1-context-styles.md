# Spec 002 — v1.1 delta: context styles, collapse & click-to-open

> Follow-up to the shipped v1. Promotes three former parking-lot items into
> scope, driven by live-testing feedback (2026-07-04). Design chosen from HTML
> mockups (`backlink-mockups.html`): variants **B (cards)** and **C (dense)**.

## Decisions (user-confirmed 2026-07-04)

1. **Two selectable context styles**: `cards` (mockup B) and `dense` (mockup C).
   - Global setting **Context style** — default **`dense`**.
   - Per-block override via a new `style: cards|dense` key.
2. **Collapsible context groups**: a chevron precedes each source; clicking the
   chevron **or** the source title folds/unfolds that group.
   - Default **expanded**; per-block override via `collapse: true|false`.
   - Global setting **Collapse context by default** (default off = expanded).
3. **Click a context line → open the source note at that line** (jump), using the
   line index already produced by `extractContext`. Lifts the v1 "no jump" limit.

Scope note: `style` and `collapse` affect **`display: context` only**. In compact
mode they are ignored (no group, no chevron). Fold state is per-block and
**not persisted** (unchanged from v1).

## Interaction model (context mode)

| Element | Click | Mod-click |
|---|---|---|
| Chevron | toggle fold | toggle fold |
| Source **title** | toggle fold | toggle fold |
| Context **line** | open source note **at that line** | open at line in a new tab |

(Compact mode is unchanged: the title opens the note; mod-click → new tab.)

## Changes by module

### `src/types/index.ts` (OrbitalSettings)
Add:
- `backlinkContextStyle: "dense" | "cards"` — default `"dense"`.
- `backlinkContextCollapse: boolean` — default `false` (expanded).

### `src/settings/SettingsTab.ts`
New heading **"In-note backlinks"** with:
- **Context style** dropdown (Dense / Cards).
- **Collapse context by default** toggle.

### `src/codeblock/BacklinkBlockConfig.ts` (pure)
Extend `BacklinkBlockConfig` with:
- `style?: "cards" | "dense"` — omitted = inherit setting; invalid value → warning.
- `collapse?: boolean` — omitted = inherit setting; accepts `true|false` (also
  `yes|no`? no — keep strict `true|false`); invalid value → warning.
Parser keys: `style`, `collapse`. Unknown-key/whitespace rules unchanged.

### `src/codeblock/BacklinkCodeBlock.ts`
- Resolve effective values: `style = config.style ?? settings.backlinkContextStyle`;
  `collapsed = config.collapse ?? settings.backlinkContextCollapse`.
- Context container gets a style class: `orbital-backlink-context--cards` or
  `--dense`.
- Each source group renders a **chevron** + title; group starts with
  `is-collapsed` when `collapsed`. Chevron/title click toggles `is-collapsed`
  (pure DOM class toggle — no re-render, no persistence).
- Each snippet row is clickable → open the source note at `snippet.lineIndex`
  (mod-click → new tab). Requires threading `lineIndex` from `extractContext`
  (already on `ContextSnippet`) into the rendered row.
  - Open at line via the existing open helper extended with an `eState: { line }`
    (mirror the `openLinkText` structural-cast pattern already used).
- Compact mode: title-click still opens (unchanged).

### `styles.css`
- `.orbital-backlink-context--dense` and `--cards` rule sets (from mockups B/C).
- Chevron rules (`.orbital-backlink-chevron`, rotate on `.is-collapsed`).

## Acceptance criteria (EARS)

- WHEN `display: context` and no `style` key, THE SYSTEM SHALL render using the
  `backlinkContextStyle` setting (default dense).
- WHERE a block sets `style: cards|dense`, THE SYSTEM SHALL use that style
  regardless of the setting.
- WHEN a context group's chevron or title is clicked, THE SYSTEM SHALL toggle
  that group's folded state without re-rendering or persisting it.
- WHILE `collapse` (block) or `backlinkContextCollapse` (setting) is true, THE
  SYSTEM SHALL render context groups folded initially; the block key overrides
  the setting.
- WHEN a context line is clicked, THE SYSTEM SHALL open the source note scrolled
  to that link's line; WHERE mod-clicked, in a new tab.
- IF `style` or `collapse` has an invalid value, THEN THE SYSTEM SHALL fall back
  (to the setting / expanded) and record an inline warning.
- THE SYSTEM SHALL ignore `style`/`collapse` in compact mode (no error).

## Out of scope (still)
- Persisting fold state across reloads.
- A third style; sort/limit; configurable target note; 2nd-hop.
